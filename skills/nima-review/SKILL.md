# Review research

Read [the shared tool and state contract](../_shared/tools.md) before acting.

Pin the exact target and revision. Read its evidence before selecting review checks.
Use Review Research, Analyze Graph, Trace Claim Dependencies and scoped Search for Counterexamples as appropriate.
Use Substantiate Graph Snapshot for represented missing-support findings; bind the result to the same target, revision and finding.
Compare competing interpretations when useful, and give concrete repair suggestions tied to evidence.
Keep failed or inconclusive checks visible. Reassess a revised target with its new identity; do not reuse a stale approval.
Save a requested review with Save Research Analysis and verify readback. Graph changes require their own exact approval.
