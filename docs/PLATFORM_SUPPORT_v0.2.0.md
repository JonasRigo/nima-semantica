# v0.2.0 qualification

The supported targets remain Ubuntu 24.04 and native Apple-silicon macOS, with Python 3.11–3.13 and the pinned Langflow stack.
Historical platform campaigns remain available in the versioned qualification documents; they do not qualify changed v0.2.0 code.

## Local qualification

The complete source and installed-wheel suites each passed 1,673 tests, with 76 optional skips and one retained adapter scheduling expected failure, on Linux with Python 3.13 and pinned Langflow 1.12.0.
The release inventory authenticates runtime and packaged resource bytes and excludes private configuration, corpora, sessions, backups and development history.

Fresh configured stdio clients and concurrent authenticated HTTP clients discovered 16 proof tools and 18 mathematics tools, retrieved exact evidence, resolved original receipt bytes and enumerated all 17 retained progress commits with canonical hashes.
The public service exposed all 21 workflows and returned one bounded Tool Guide representation per call.
Original model and embedding connection nodes and edges survived the deployment refresh.

The maintained migration authenticated all 165 receipt references of a completed proof session while preserving its revision and lifecycle.
All 12 retained proof sessions, action and replay hashes, and six accepted native inspection/replay pairs matched consistent pre-upgrade backups.
A native Lean operation completed in 309.758 seconds with independent inspection and kernel replay under the selected operator policy.
Its source correspondence remained separately unverified.

## Hosted qualification

The [GitHub tests workflow](https://github.com/JonasRigo/nima-semantica/actions/workflows/tests.yml) builds the curated source archive and wheel, checks their inventories and installs that wheel outside the source tree.
Nine core jobs cover Ubuntu 24.04 and native ARM64 macOS 15/26 with Python 3.11, 3.12 and 3.13.
Three additional jobs exercise pinned Langflow on those operating systems with Python 3.11.
Linux jobs also build and exercise the isolated symbolic worker.
Together with the packaging job, these provide 13 required hosted jobs.
The v0.2.0 GitHub release records the exact qualified commit, workflow run, per-platform results and distribution checksums; JUnit reports are attached to that run.

Skipped optional integrations are not counted as passes.
Hosted macOS jobs do not exercise Docker Desktop, and local Linux live checks do not establish a new macOS full-stack qualification.
Intel Macs, Rosetta and other Linux distributions are outside this hosted platform claim.
Parallel extraction and exhaustive scientific verification remain outside this release.
