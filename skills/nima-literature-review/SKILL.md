# Literature review

Read [the shared tool and state contract](../_shared/tools.md) before acting.

Pin the review question and corpus/project scope. Inspect prepared coverage before new discovery.
Use Deep Research with focused questions and authorized providers; retain source-attributed graph proposals and remaining questions.
For existing prepared papers, retrieve and read exact regions rather than relying on metadata.
A fast-read result is provisional. To make it durable project knowledge, prepare its selected files, reconcile citations with exact prepared regions, and use the explicit graph-update approval boundary.
Compare agreements, assumptions, differences and unanswered questions; preserve contradictory sources.
For saved reviews, use Save Research Analysis and read back the artifact. For requested LaTeX output, use the shared report template.
If discovery or full text is unavailable, retain the failed receipts and state the remaining coverage question.
