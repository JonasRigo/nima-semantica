# Conditional conventions for NQS, SCOL and operator constructions

Use these conventions only when the represented method is actually the subject of the figure.
Read the current project's definitions and algorithm before drawing algorithm-dependent operations.

## NQS

Use a correlated-electron network when that metaphor clarifies the material-to-response argument, and explain it in the companion.
For amplitude-based NQS, show configuration inputs, hidden layers and one output representing the complex scalar `$\psi_\theta(s)$` for the supplied configuration.
Neuron counts are schematic.
Label the amplitude nearby when space permits and explain configuration evaluation in the companion.
Use multiple outputs or an autoregressive architecture only when explicitly explaining such an architecture.
Keep ground-state observables and spectral response as separate visible branches and keep candidate descriptions distinguishable throughout the comparison.

## SCOL

Use a recognizable glass prism when it clarifies the material-to-response argument.
Give it transparent surfaces, visible facets and edges, restrained reflections and refraction; inspect it against white so it reads as glass rather than a solid triangular wedge.
Explain the prism metaphor in the companion.
For support selection, show candidate operator-state vectors relative to the current selected span, distinguishing represented components, genuinely novel components and redundant candidates.
For the user's current Algorithm 2, admission depends on novelty and aggregate packet-residual gain, followed by full coefficient refitting; verify that the current project still uses this algorithm before drawing it.
Distinguish coherent Banach packet generation, shared-word compression and the final projected packet response.
Abstract planes represent illustrative slices of state space rather than literal physical surfaces.

## Operator constructions

Show growing strings through site-aligned local factors and identities, label spatial span and preserve fermionic factor order.
For commutator propagation, place `$\mathcal{L}(\hat{O})=[\hat{H},\hat{O}]$` beside transitions between successive operator expressions and identify individual bond actions for selected contributions.
Retain the signs and coefficients needed to understand the depicted construction.
Align the physical explanation with the mathematical operation at the same location.
