# Research skills

A skill gives your coding agent a method for using NIMA’s tools.
You choose the question and judge the result; your agent can revise its approach as evidence changes.
We keep this guidance separate from the tool implementation so that a proof, a literature review and a calculation can use different reasoning strategies over the same persistent evidence.

Project initialization installs these ten skills for your selected harnesses.
Name a skill in your request, or ask your agent to choose the appropriate one.

| Skill | Use it to |
| --- | --- |
| [Chat with the knowledge base](nima-corpus-chat.md) | Explain the assumptions in my project notes using the corpus papers, and cite the exact passages. |
| [Ingest papers](nima-ingest.md) | Prepare a paper list in full or fast mode, extract with an ontology, and review graph additions. |
| [Research](nima-research.md) | Investigate whether this approximation applies to my project, retaining assumptions and unresolved checks. |
| [Literature review](nima-literature-review.md) | Review the literature on this question, compare the approaches and identify what the available sources do not settle. |
| [Review research](nima-review.md) | Review this argument against its cited sources and test the consequential assumptions. |
| [Critique research](nima-critique.md) | Audit the current project argument for evidence gaps, conflicts and useful repair steps. |
| [Calculate mathematics](nima-calculate-mathematics.md) | Derive this quantity from the stated assumptions, record the intermediate steps and check the result. |
| [Draft proof](nima-draft-proof.md) | Develop alternative proof strategies for this statement and identify the lemmas each route needs. |
| [Conduct proof](nima-conduct-proof.md) | Develop this argument in a private proof graph and check each consequential step. |
| [LaTeX to Lean](nima-latex-to-lean.md) | Formalize this LaTeX statement in Lean and verify the exact declaration in the configured environment. |

For installation and resumption, see [projects](../PROJECTS.md).
For exact callable interfaces, see the [tool catalogue](../TOOLS.md).
