# Literature review

Use `nima-literature-review` when you want the following outcome: a cited review with coverage limits and a saved analysis. Fast-read passages require exact reconciliation before graph admission.

## Ask your agent

> Use `nima-literature-review`: Review the literature on this question, compare the approaches and identify what the available sources do not settle.

Project initialization installs this skill for your selected harnesses.
See [projects and harness connections](../PROJECTS.md) if it is not available in a new session.

## Before you start

Define the review question and scope; decide whether new literature discovery is needed.

## How the investigation proceeds

Inspect prepared coverage, use Deep Research for discovery and synthesis, prepare selected sources, compare claims and save the review.
These steps guide your agent’s choices; adapt them to the evidence and the task.

## What you keep

A cited review with coverage limits and a saved analysis. Fast-read passages require exact reconciliation before graph admission.
Save substantive analyses through [Save Research Analysis](../tools/save_research_analysis.md) and inspect the returned artifact IDs.
Admit selected graph changes through [Update Project Graph](../tools/update_project_graph.md) with exact approval.
For a new chat, retain the project binding and relevant artifact or private session IDs, then inspect the current state before continuing.
