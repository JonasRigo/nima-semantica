# Critique research

Read [the shared tool and state contract](../_shared/tools.md) before acting.

Pin the requested audit scope and project graph revision.
Use graph analysis and dependency tracing to select concrete questions; inspect exact source evidence before interpreting a represented gap.
Use Review Research and other specialist tools where they address those questions. Missing support is not a counterexample.
Report each finding with target, evidence, severity, uncertainty and a useful next check or repair.
Compare alternatives when the evidence supports multiple readings.
Save requested findings with Save Research Analysis. Never rewrite the project graph as an implicit consequence of critique.
