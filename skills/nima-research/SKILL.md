# Research

Read [the shared tool and state contract](../_shared/tools.md) before acting.

Establish the question, current corpus/project scope and relevant existing knowledge.
Retrieve exact evidence and inspect represented dependencies. Choose Hypothesis Generation, Compare Research Objects, Deep Research, calculation, proof, review or formalization according to the question.
Route calculation and proof work through their private-graph skills; they can return partial results with exact outstanding obligations.
Use Deep Extraction when source-grounded graph proposals help the investigation.
Revisit the question when new evidence changes assumptions or contradicts the selected route.
For requested persistence, save the analysis and obtain the exact approved project update; preserve failed alternatives as history.
Finish with the supported result, evidence IDs and concrete remaining work.
